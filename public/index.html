01Recorrido

La pista

Un hangar con luz natural, asfalto real y bordillos de competición. Rectas para soltar el gatillo y curvas para afinar la trazada.

02Complejo

Complejo de radio control indoor

Pista de asfalto de 1.000 m², iluminación nocturna, boxes para 60 pilotos y un ecosistema completo para rodar, competir y aprender.

  • 01

    Pista de asfalto

    Curvas, rectas y siete trazados modulares para buscar tu mejor vuelta.

  • 02

    Pista de Crawling

    Circuito de obstáculos y rocas para avanzar con precisión y control.

  • 03

    Pista de rally

    Superficie mixta de asfalto y tierra para cambiar de ritmo en cada tramo.

  • 04

    Circuito para drones

    Obstáculos y gates modulares para volar bajo presión y encontrar la línea.

  • 05

    Simuladores FPV

    Simuladores de carreras y manejo en primera persona para entrenar todo el año.
